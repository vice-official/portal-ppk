# Единый реестр граждан

Веб-приложение для мониторинга аналитических показателей и оперативного учета граждан. Реализовано на базе современного стека фронтенд-разработки с соблюдением требований модульной архитектуры и строгой типизации.

## Стек

* **Frontend:** React, TypeScript
* **Сборка:** Vite
* **UI-компоненты:** Material UI
* **Серверное состояние и кэширование:** TanStack React Query
* **Визуализация данных:** Recharts
* **Маршрутизация:** React Router
* **Генерация данных:** `@faker-js/faker/locale/ru`
* **Тестирование:** `Vitest, React Testing Library, jsdom`
* **Тестирование компонентов:** `Storybook 10` 

## Архитектурные решения

1. **Обработка масштаба 100 000+ записей:**
  * Реализован виртуальный API-сервис (`citizenApi.ts`) с эмуляцией серверной пагинации, фильтрации и многопараметрической сортировки на стороне источника данных.
  * Клиентский DOM не перегружается: рендерится ровно то количество строк (`pageSize`), которое запросил пользователь, что гарантирует стабильные 60 FPS при прокрутке и взаимодействии.
  * Аналитический срез (`getDashboardStats.ts`) использует масштабирующий коэффициент (scale factor) относительно генеральной совокупности, позволяя мгновенно агрегировать когорты, статусы и динамику без задержек.

2. **Оптимизация сетевых запросов и UX:**
  * Поиск по строке оснащен хуком `useDebounce` (300 мс), предотвращая частые повторные вызовы API во время ввода символов.
  * В React Query включено свойство `placeholderData: (prev) => prev`, устраняющее неприятное мерцание таблицы при переключении страниц пагинации.
  * На экране дашборда и таблицы внедрены скелетоны загрузки (`Skeleton`), предотвращающие сдвиги макета (Cumulative Layout Shift).

3. **Структура проекта:**
  * Проект организован по принципам Feature-Sliced Design (FSD):
    * `src/app/` — корневые провайдеры, тема и маршрутизация.
    * `src/entities/` — типы бизнес-сущностей (`Citizen`, `FamilyMember`, `EducationRecord`).
    * `src/features/` — независимые функциональные блоки (`dashboard`, `registry`, `person-card`).
    * `src/pages/` — композиционные экраны (`DashboardPage`, `CitizensRegistryPage`, `CitizenDetailPage`).
    * `src/shared/` — библиотеки форматирования, API-клиенты и утилиты.

## Запуск проекта

1. Установка зависимостей:
   ```
   npm install
   ```
2. Запуск сервера разработки:
   ```
    npm run dev
   ```
Проверка типов и сборка продакшен-бандла:
  ```
  npm run build
  ```

## Тестирование
